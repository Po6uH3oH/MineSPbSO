# Проверки версии 0.2.0

На отдельной копии библиотек и модов рабочего сервера с новым миром, отдельной SQL-базой и временными портами проверен полный путь. Настоящий клиент получил community-gate из лаунчера, подключился через TLS, получил билет через локальный брокер, вошёл в мир и загрузил текстуру скина. Сервер записал ожидаемый UUID в whitelist.json. Блокировка удалила допуск и отключила активного игрока; разблокировка восстановила запись. При входе вторым клиентом с точными ником, UUID, сборкой и сфабрикованным билетом сервер отказал до создания игрока. Отдельный незаверенный Login Start под уже занятым ником был отклонён до отключения владельца.

Автоматические SQL-сценарии проверяют недоступность списка без служебного ключа, отсутствие неподтверждённого аккаунта, несовпадение сессии и ника, истечение, конкурентное повторное погашение билета, отзыв сессии и блокировку. Команда повторения игрового теста — scripts/tester-e2e.ts через tsx с GATE_SERVER_TEMPLATE, указывающей на готовый сервер с принятым EULA, и необязательным TESTER_SMOKE_ENGINE с кешем Java/Minecraft. Нужны подготовленные тестовые ключи, подписанный модпак и собранный dist/app.

Рабочий сервер владельца требует явного переключения, см. [инструкцию](PROTECTED-SERVER.md). Межмашинное подключение защищённого сервера к API на VDS ещё не прогонялось на реальной инфраструктуре.

# Проверки версии 0.1.5

На английской Windows Server 2025 запуск Java внутри каталога с кириллицей первоначально завершался ошибкой «could not find java.dll». Лаунчер теперь создаёт проверенную ссылку на тот же экземпляр по пути с латинскими символами и использует её для Java и установщика. Данные игрока остаются в исходном каталоге.

[Чистая проверка на отдельной Windows](https://github.com/Po6uH3oH/MineSPbSO/actions/runs/41360180743/job/125008696523) завершилась успешно. В пустую папку «Чистый клиент» скачаны отдельная Java 21.0.7, Minecraft 1.21.1, библиотеки и assets. Официальный установщик создал версию neoforge-21.1.256 без Modrinth. Проверены java.exe -version и установленный JSON версии.

Отдельный тест 0.1.5 на ПК владельца повторил загрузку 565421610 байт по подписанному списку и повторный запуск без новых запросов за модами. Electron запустил клиента LayerNetTest, клиент вошёл на работающий Minecraft-сервер и запросил профиль и текстуру CustomSkinLoader. Проверки не требуют отправки пароля или refresh token в игру.

Чистая установка в облаке и вход в игровой мир проверены раздельно. Полный путь через Porthole с компьютера приглашённого тестера и визуальное сравнение скина у двух игроков остаются ручными сценариями. Сборка серверного мода прошла на GitHub, проверка защиты ника этим модом на рабочем сервере ещё требуется.
# Проверки версии 0.1.4

TypeScript, 17 автоматических тестов и отдельная проверка интерфейса Electron прошли. Проверены валидация IP, сохранение адреса, извлечение ZIP по манифесту, обновление источника скинов с сохранением пользовательской конфигурации.

Проверка на настоящем сервере подтвердила Minecraft 1.21.1 по 127.0.0.1 и 10.99.52.8, онлайн 0/20 до подключения и HTTP 200 BlueMap. В изолированный экземпляр по HTTPS передано 565421610 байт в 551 запросе уникальных файлов. Установлено 607 файлов. При повторной установке запросов за файлами не было.

Реальный клиент LayerNetTest вошёл в мир по нажатию «Играть» на 127.0.0.1:48905. В журнале зарегистрирована загрузка 475 достижений. CustomSkinLoader загрузил профиль и текстуру тестового аккаунта и выбрал модель default. Голосовой сервер подтвердил соединение. Запись второго игрока и визуальная проверка скина на втором мониторе ещё требуются.

Java и Minecraft скачаны в отдельный экземпляр. Для успешного игрового входа использовался установленный NeoForge из Modrinth. В новом каталоге без кеша проверена остановка за девять секунд при недоступном Maven. Полная онлайн-установка загрузчика на физическом втором ПК остаётся проверкой тестера. Облачная ссылка владельца пока отсутствует. Полная сборка реально проверялась через пофайловую раздачу, ZIP проверялся отдельным тестом. Рабочая защита ника серверным модом пока требует отдельной интеграционной проверки.
# Проверки версии 0.1.3 — 1 ноября 2026

## Автоматически

- TypeScript: `node node_modules/typescript/bin/tsc --noEmit` — успешно.
- `node node_modules/tsx/dist/cli.mjs --test tests/*.test.ts` — 14 тестов, 14 успешно. Аккаунты на реальном SQL PGlite, коды/сессии/билеты, стабильный UUID, подписи манифестов, безопасные пути, восстановление модов после сбоя, сохранение данных, возобновление и проверка загрузок, скины API, TLS/broker.
- Новые проверки: XMCL формирует аргументы с точным ником аккаунта и UUID, отдельной Java, путями с пробелами и кириллицей, без quick-play для локальной игры и с loopback quick-play для серверного режима. Это проверка аргументов, не реального серверного подключения.
- Импорт Modrinth включает результат патчера Minecraft, исключает installer-only библиотеки из runtime classpath, сохраняет источник и отклоняет повреждённые библиотеки/отсутствующий patched client.
- Локальный модпак копирует шесть разрешённых компонентов, не переносит saves, сохраняет пользовательский options.txt.
- `scripts/ui-smoke.ts` — реальный Electron и изолированный сервис: регистрация → код → вход, восстановление пароля, отсутствие фракций и нативного меню, упрощённые подписи, изоляция Node, сохранение сессии, памяти, темы и выбранной папки после перезапуска. Письма в этом тесте перехватываются callback, SMTP не тестируется. Системный диалог выбора папки подменён тестовым ответом; IPC и сохранение пути настоящие.

Машиночитаемый результат интерфейса: `docs/research/ui-smoke-result.json`.

## Сборка Windows

`node scripts/build.mjs` и `electron-builder --win nsis --x64 --publish never` завершились успешно. Получен `release/MineSPbSO-0.1.3-Setup.exe`, 131998615 байт, без сертификата подписи Windows. `scripts/verify-release.mjs` сверил файлы в app.asar с текущей сборкой и конфигурацию с публичным примером. SHA-256 установщика: `4a3f775bd02de39a85c318ac0309f16a14ee17dfd13afbd47a18697b70946775`; рядом записан `.sha256`. Контрольная сумма помогает выявить повреждение, но не заменяет цифровую подпись издателя. Установка этого пакета поверх 0.1.2 пока остаётся ручной проверкой владельца.

## Реальный игровой запуск

На Windows запущены Minecraft 1.21.1 / NeoForge 21.1.256 с 157 JAR исходного профиля LAYER BETA 0.0.0. Пользователь подтвердил вход в игру под техническим ником LauncherTest. В `.local/Тест запуска сборки/game/logs/latest.log` есть загрузка одиночного мира и сохранение его измерений. Путь экземпляра содержит пробелы и кириллицу. Использована отдельная Java в каталоге экземпляра, не системная Java.

Тест использовал ранее подготовленные Minecraft/Java и установленный кеш Modrinth, поэтому **не является доказательством чистой установки на новом компьютере**. Ник обычного лаунчера берётся из `/me`; вход в мир под реальным аккаунтом через установленную версию 0.1.3 остаётся ручным сценарием владельца.

## Оставшиеся проверки

- Чистая установка через официальный Maven NeoForge отложена: пользователь сообщил, что Maven offline. Доступность в этом продолжении не перепроверялась. Использование локального кеша не подтверждает работоспособность онлайн-установщика.
- Полный цикл «установщик → аккаунт владельца → Играть → мир → повторный вход» на компьютере владельца и на другом компьютере.
- Обрыв/дефицит места в полном установщике Java/Minecraft, не только в отдельном файловом updater. Нехватка диска пока не была воспроизведена.
- Компиляция и реальное подключение с community-gate, отклонение подмены ника до мира, работа при недоступном API. Сервисные тесты не заменяют эту проверку.
- Два клиента с пользовательскими скинами, кит после перезапуска сервера, FTB-права, голос и глобальная активация datapack.
- Установщик без сертификата Windows; доверенное самообновление, VPS и публикация ещё не проверены. Проект никуда не опубликован.

Фракции исключены из пользовательского сценария по просьбе владельца. Полный проект ещё не считается готовым к публичному размещению.
