# Восстановление MineSPbSO на Windows

Если 0.2.0 или 0.2.1 просит удалить operation.lock, закрой Minecraft и лаунчер. Если окно исчезло и непонятно, осталась ли игра работать, перезагрузи компьютер. Установи 0.2.2 поверх прежней версии. Открой **Разработчикам → Проверить состояние игры**, затем нажми **Играть**. Кнопка проверяет занятость экземпляра и автоматически убирает оставшуюся отметку. Живые процессы закрываются обычным выходом из игры.

В 0.2.2 для освобождения места открой **Разработчикам → Очистить кеш загрузок** перед удалением программы. Следующая установка может заново скачать эти файлы. При обычном удалении через «Установленные приложения» выбери «Да», чтобы стереть сохранённый вход на этом компьютере. Для отзыва сессии на сервере сначала выйди через «Аккаунт». Миры, настройки и установленные файлы игры остаются в папке экземпляра.

Для полного удаления данных старой версии перезагрузи ПК, удали приложение, нажми Win+R и открой `%APPDATA%\\community-smp`. Скопируй эту папку в резервную копию, если нужны игровые данные. Для очистки одного входа удали только `session.bin`. Для полного сброса удали папку community-smp после резервного копирования. Если нужно оставить старую версию, после перезагрузки и до запуска лаунчера можно удалить только `instance\\operation.lock`.

В **Разработчикам** включи журнал, повтори проблемное действие и нажми **Открыть папку журнала**. В launcher.log сохраняются этапы, сбои операций и код выхода Java. Предыдущая часть сохраняется как launcher.log.1. Для сбоя самой игры пригодится также instance/game/logs/latest.log. Проверь содержимое игрового лога перед отправкой.
