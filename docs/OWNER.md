# Запуск на компьютере владельца

Один раз настрой защищённый тестовый сервер по [PROTECTED-SERVER.md](PROTECTED-SERVER.md). Общий запуск использует те же ключи, мод и папку тестового сервера.

1. Если сервисы уже запущены по отдельности, в старом окне Minecraft введи `stop`, дождись сохранения мира, затем останови прежние аккаунты, раздачу и шлюз.
2. Подключи Porthole и дважды щёлкни **Start-MineSPbSO.cmd** в корне проекта. Если папка сервера отличается от Desktop/test_server, перетащи её на этот CMD-файл.
3. В отдельное маскированное поле вставь пароль приложения Яндекс Почты с помощью **Ctrl+V**. Нажми **Запустить**. Пароль передаётся службе аккаунтов через память, скрипт не записывает его на диск. По умолчанию указан логин владельца bruh1bruh1bruh, переопределить его можно переменной YANDEX_LOGIN.
4. Дождись строки Minecraft **Done**. В общем окне видны сообщения четырёх сервисов. Для завершения введи **stop** и дождись закрытия окна.

## Панель владельца

В .env.local в корне проекта добавь строку вида `ADMIN_PANEL_PASSWORD="…"`, заменив многоточие отдельным паролем длиной от 20 символов. Используй случайный пароль из менеджера паролей. Перезапусти сервис аккаунтов. На компьютере владельца открой http://127.0.0.1:3011 и введи логин **owner** и этот пароль. Без настройки панель выключена.

В списке видны ник, почта, дата создания, подтверждение почты и допуск. В форме управления введи точный ник. Замена пароля отзывает сессии лаунчера и ранее выданные коды восстановления. Чтобы отключить уже играющего пользователя, выполни kick в консоли Minecraft. Для удаления потребуется повторить ник. Почта освобождается, ник резервируется, игровой мир и файлы игрока остаются на сервере.

При ручном допуске новый игрок подтверждает почту и ждёт одобрения. Для допуска выбери «Одобрить» и укажи ник. Режим закрытой регистрации прекращает приём новых заявок. Изменение режима не меняет допуск уже созданных аккаунтов.

## После переноса на VDS

Для Docker Compose задай ADMIN_PANEL_PASSWORD в серверном .env и пересоздай сервис командой `docker compose up -d --build accounts`. На хосте порт 3011 привязан к loopback. Не добавляй его в публичный reverse proxy. На своём ПК выполни `ssh -N -L 3011:127.0.0.1:3011 user@your-server`, подставив свой SSH-логин и адрес VDS, затем открой тот же локальный адрес панели. Для выхода из панели, использующей встроенный парольный запрос браузера, удобно закрыть приватное окно браузера.
