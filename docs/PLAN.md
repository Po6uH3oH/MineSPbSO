# План и критерии готовности

Начало: 31 октября 2026. Исходная папка пустая, Git не инициализирован.

1. В работе: воспроизводимая установка Minecraft 1.21.1 / NeoForge 21.1.256 / отдельной Java 21; проверка настоящих API configuration-фазы и компиляция мода.
2. Проверка аккаунта до мира: стабильный offline UUID, одноразовая проверка текущего подключения, TLS для offline-транспорта, fail-closed. Критерий: тесты подмены/повтора/истечения и подключение настоящего клиента.
3. Подписанный выпуск: SHA-256, безопасные пути, атомарное переключение управляемых файлов, сохранение данных, откат. Полная сборка разрешается только после аудита реальных JAR и лицензий.
4. Регистрация, почта, восстановление, PostgreSQL, Electron UI на русском, системное хранение сессии.
5. Скины, заменяемый адаптер китов с сохранением состояния. Фракции отложены по просьбе владельца.
6. NSIS, обновление лаунчера, Compose, CI, инструкции и отдельный отчёт проверок.

Этап считается завершённым только после проверки работающего компонента. Сборка интерфейса не подтверждает запуск игры. Непроверенные интеграции отмечаются отдельно. Публикация и покупка услуг не выполняются.
