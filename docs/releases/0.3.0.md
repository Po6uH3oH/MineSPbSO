# MineSPbSO 0.3.0

Полностью обновлённый интерфейс лаунчера для Windows x64.

- Сине-голубая палитра, тёмная и светлая темы, фоны мира MineSPbSO.
- Окно без стандартной рамки, собственные кнопки сворачивания и закрытия, перетаскивание за верхнюю область.
- Обязательный вход перед доступом к вкладкам. Запоминание сессии включено по умолчанию; пароль не сохраняется. Отдельный переключатель автовхода в настройках.
- Ошибки данных отображаются рядом с формой. При сбое сервиса открывается экран подключения с повторной попыткой и копируемыми подробностями.
- Выезжающее боковое меню с иконками; ник справа открывает аккаунт.
- Состояние сервера и онлайн. При наведении или фокусе на счётчике — имена, которые сервер включил в ответ. Сервер может передавать только часть списка либо не передавать его.
- Обычная и улучшенная сборки для слабых и мощных ПК. Рекомендации: 4 и 6 ГБ. Выделение ограничено доступной общей памятью, при запуске дополнительно проверяется свободная память.
- Параметры окна Minecraft, полный экран, автоподключение к серверу и дополнительные аргументы JVM.
- Сохранены регистрация, подтверждение почты, восстановление пароля, скины, обновления, выбор папки сборки, диагностика и обслуживание.

## Установка

Скачайте `MineSPbSO-0.3.0-Setup.exe` и установите поверх текущей версии. Пользовательская игра, сессия и настройки находятся отдельно от приложения. Вход выполняется по почте и паролю существующего аккаунта MineSPbSO.

## Графические режимы

Переключатель использует графический набор в подписанном манифесте. Владельцу нужно подготовить список необязательных модов в `launcher-graphics.json` и заново опубликовать сборку: [инструкция](https://github.com/Po6uH3oH/MineSPbSO/blob/main/docs/GRAPHICS-PROFILES.md). Без этого списка лаунчер не сможет самостоятельно разделить существующие моды по мощности ПК. Совместимость конкретных наборов требует проверки в игре.

Minecraft 1.21.1, NeoForge 21.1.256 и Community Gate 0.2.0 сохранены. Выпуск остаётся тестовым, как предыдущие релизы проекта.
