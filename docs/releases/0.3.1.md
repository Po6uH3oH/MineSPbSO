## MineSPbSO 0.3.1 для Windows x64

Упрощены главная страница, шторка, аккаунт, настройки и диагностика. Названия разделов и статистика сервера стали крупнее. Логотип использует Minecraft Ten Cyrillic, кнопки — Ithaca, основной текст — Classic Console Neue. В аккаунте отображается голова загруженного скина.

Память можно установить с шагом 1 МБ ползунком или ввести точное число. Лаунчер переносит прежнюю настройку из ГБ. Рекомендации составляют 4096 МБ для обычной и 6144 МБ для улучшенной сборки.

| Профиль LAYER BETA | Шейдеры при запуске | Дальность Minecraft | Радиус Distant Horizons |
| --- | --- | --- | --- |
| Обычный | Выключены | 6 чанков при выборе профиля | 16 чанков |
| Улучшенный | Complementary Unbound r5.9.3 | 12 чанков при выборе профиля | 48 чанков |

Улучшенный профиль добавляет семь графических модов. Шейдерпак скачивается по подписанному манифесту при выборе улучшенного режима. В обычном режиме уже скачанный ZIP остаётся на диске, Iris отключает его перед запуском игры.

Для установки скачайте `MineSPbSO-0.3.1-Setup.exe`. [Настройка графического профиля](https://github.com/Po6uH3oH/MineSPbSO/blob/main/docs/GRAPHICS-PROFILES.md).
