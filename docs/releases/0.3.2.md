## MineSPbSO 0.3.2 для Windows x64

На главную возвращены приглашение на сервер и описание. Кнопки используют Classic Console Neue. Ithaca удалён из приложения. Размеры текста увеличены по всему интерфейсу, отключено искусственное утолщение шрифта.

Окно закреплено на 1100 × 760. Изменение размера и разворачивание отключены для стабильной раскладки.

Для установки скачайте MineSPbSO-0.3.2-Setup.exe.

Описание на главной занимает три строки. Описание, состояние сервера и название сборки используют приглушённый цвет. Шторка расширена под названия вкладок.
