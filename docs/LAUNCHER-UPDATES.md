# Обновления лаунчера с 0.2.1

Для первого перехода с 0.2.0 установи проверенный 0.2.1 поверх прежней версии. Мод Community Gate остаётся версии 0.2.0. При дальнейших выпусках лаунчер сам проверит подписанный канал при запуске. При появлении более новой версии нажми «Скачать», затем «Установить и перезапустить». Откроется обычный установщик Windows. В «Настройки → Дополнительно» доступны ручная проверка и страница выпусков приватного репозитория.

На ПК владельца перезапусти раздачу (start-testers.ps1 из обновлённого проекта). Для подготовки следующего обновления скачай EXE опубликованного выпуска, сверь SHA-256 с GitHub, выполни из папки проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\scripts\prepare-launcher-update.ps1 -Installer 'ПУТЬ_К_EXE' -Sha256 'SHA256_ВЫПУСКА'
```

Скрипт копирует неизменяемый файл в раздачу и последним подписывает и переключает метаданные. Для этого используется закрытый ключ владельца из .local/tester-keys. Игроку доступ к GitHub для этого пути не нужен. Лаунчер проверяет назначение и подпись метаданных, номер версии, размер и SHA-256. Перед открытием EXE контрольная сумма проверяется ещё раз. Подпись обновления действует в лаунчере, отдельного сертификата Authenticode Windows у проекта пока нет. Сессия и игра хранятся вне каталога установленного приложения.

## Проверка Defender

На ПК владельца журнал Microsoft Defender (событие 1116) зафиксировал Program:Win32/Contebrew.A!ml при загрузке MineSPbSO-0.2.0-Setup.exe. SHA-256 файла из «Загрузок» совпал с GitHub: f43c11255963e37420ad8fe6b4e95c0654ff1f46a32db9b577302ce39a6ff8ac. Повторное локальное сканирование именно этого файла было пропущено самим Defender. Это не даёт нового вердикта для 0.2.0.

В 0.2.1 упаковка ограничена файлами собранного клиента. Удалены лишние серверные зависимости и вспомогательный elevate.exe, который не нужен для обновления от текущего пользователя. Причина классификации Microsoft не установлена. Публикация нового установщика требует фактически выполненного Defender-сканирования конкретного файла. Обнаружение угрозы, пропущенный скан или неработающий антивирус останавливают выпуск.

Для пересмотра прежней классификации можно обратиться в [Microsoft Security Intelligence](https://www.microsoft.com/en-us/wdsi/filesubmission) как Software developer и указать детект, SHA-256 и время обнаружения (2 ноября 2026, около 17:39 МСК). На момент проверки веб-форма принимает файлы до 50 МБ; прежний установщик больше лимита. Для передачи полного образца потребуется согласованный с Microsoft канал. Приватный бинарник в Microsoft автоматически не отправляется.
